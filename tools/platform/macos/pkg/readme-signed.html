This installer is signed, but not notarized

It carries a Developer ID signature, so you can see who made it — but Apple has not checked it. Since macOS Catalina that is not enough on its own for a downloaded file, so a double-click may still report that it “cannot be opened”. Close that and right-click the .pkg and choose Open, then Open again.

The applications it installs are signed with the same identity and run under the hardened runtime. None of them needs xattr -dr com.apple.quarantine.
