This installer is not signed

If a double-click reported that it “cannot be opened because it is from an unidentified developer”, close that and right-click the .pkg and choose Open, then Open again. You have already done this if you are reading it.

This build was made without a Developer ID identity. It is the same honesty the Windows setup carries about SmartScreen’s “Windows protected your PC”.

The applications this places are a different matter and open normally. The quarantine flag is put on the file you downloaded, and files written out of an installer package do not inherit it — so unlike the zip of a .app, there is no xattr -dr com.apple.quarantine to run afterwards.
