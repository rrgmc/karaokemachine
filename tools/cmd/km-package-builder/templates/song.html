{# The whole file, one row per channel: what it plays, how much of it there is, what the melody detector made of it, and every correction it can be given. The Details tab carries the one correction somebody reaches for while listening; this is where somebody goes having decided the file itself is wrong. **Melody is evidence and not the confidence on the Details panel.** Confidence folds in how far the winner stood clear of the field, which is a property of the song; evidence is the channel's own signals, which is what can be put in a column beside the others. The number is the mark: above nine tenths it is coloured, and a column of numbers to compare needs no second column naming the largest. **The column is also where the melody channel is chosen**, because the evidence and the choice are the same question and a page that showed one and took the other elsewhere would be asking somebody to remember a table while looking at a select. A song detection abstained about is exactly the one somebody opens this tab for. The drum channel has no radio: it sounds a kit rather than a part. Leaving the table as it was found stores nothing, so a song goes on being detected until somebody actually changes a control -- see `crate::fixes::selection` and `crate::fixes::melody_selection`. #}
