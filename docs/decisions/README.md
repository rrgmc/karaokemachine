# Decisions

Every product-level decision, with the reasoning that produced it. A decision here is authoritative:
where an architecture note disagrees with one, the note is out of date.

**A new product decision gets written down here**, and it is the one convention in the repository
worth protecting. What the product must do is here too — a requirement and the decision that serves
it are the same entry. How the thing is built is [`ARCHITECTURE.md`](../ARCHITECTURE.md).
