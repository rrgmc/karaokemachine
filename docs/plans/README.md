# Plans

One file per feature or port being built: what will be built, and in which milestones. A plan is not
a decision, and it is deleted in the change that finishes the work, once what it found has moved to
`docs/architecture/` and `docs/decisions/`. A folder holding only this file means nothing is being
built to a plan. The convention is
[`A new feature or port may carry a committed plan`](../decisions/repository.md#a-new-feature-or-port-may-carry-a-committed-plan).
